║           FaceFusion 多人脸换脸 - 快速参考卡片                  ║
╚══════════════════════════════════════════════════════════════════╝

┌──────────────────────────────────────────────────────────────────┐
│ 三种模式对比                                                     │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│ 1. 多人脸模式 (Many)                                            │
│    ✓ 替换所有人脸                                               │
│    ✓ 最简单，一键完成                                           │
│    ✓ 可配合过滤条件（性别、年龄、种族）                         │
│    使用场景：合影照片、群体视频                                 │
│                                                                  │
│ 2. 参考人脸模式 (Reference) ⭐ 推荐                             │
│    ✓ 精确控制，只替换特定人物                                   │
│    ✓ 可在画廊中选择要匹配的人脸                                 │
│    ✓ 自动追踪整个视频中的该人物                                 │
│    使用场景：视频中有多人，只想换其中一个                       │
│                                                                  │
│ 3. 单人脸模式 (One)                                             │
│    ✓ 每帧只替换一张脸                                           │
│    ✓ 根据规则选择（最大、最左、最优等）                         │
│    使用场景：简单场景，只有一个主角                             │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ 参考人脸模式详细步骤（最常用）                                   │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│ 步骤 1: 上传文件                                                │
│   SOURCE → 上传你想要的人脸图片                                 │
│   TARGET → 上传需要换脸的视频                                   │
│                                                                  │
│ 步骤 2: 选择模式                                                │
│   人脸选择器模式 → 选择"参考人脸"                               │
│   （此时会出现"参考人脸"画廊）                                  │
│                                                                  │
│ 步骤 3: 选择要替换的人脸 ⚠️ 重要                               │
│   方法 1: 如果画廊已显示人脸                                    │
│     → 直接点击要替换的人脸缩略图                                │
│                                                                  │
│   方法 2: 如果画廊是空的或没有想要的人脸                        │
│     → 拖动"预览帧"滑块，找到包含该人脸的帧                      │
│     → 画廊会自动更新显示当前帧的所有人脸                        │
│     → 点击选择要替换的人脸                                      │
│                                                                  │
│ 步骤 4: 调整匹配严格度                                          │
│   参考人脸距离 → 推荐设置 0.6-0.8                               │
│     • 0.5-0.6 = 非常严格（只匹配几乎相同的脸）                  │
│     • 0.6-0.8 = 适中（推荐）                                    │
│     • 0.8-1.0 = 宽松（可能匹配不太相似的脸）                    │
│                                                                  │
│ 步骤 5: 选择处理器                                              │
│   勾选 face_swapper                                             │
│   （可选）勾选 face_enhancer 提升质量                           │
│                                                                  │
│ 步骤 6: 开始处理                                                │
│   点击"开始"按钮                                                │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ 多人脸模式详细步骤（最简单）                                     │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│ 步骤 1: 上传文件                                                │
│   SOURCE → 源人脸图片                                           │
│   TARGET → 目标视频                                             │
│                                                                  │
│ 步骤 2: 选择模式                                                │
│   人脸选择器模式 → 选择"多人脸"                                 │
│                                                                  │
│ 步骤 3: 配置排序（可选）                                        │
│   人脸选择器顺序 → 选择排序方式                                 │
│     • 从优到劣（推荐）                                          │
│     • 从大到小                                                  │
│     • 从左到右                                                  │
│                                                                  │
│ 步骤 4: 配置过滤（可选）                                        │
│   性别 → 只替换男性或女性                                       │
│   年龄范围 → 只替换特定年龄段                                   │
│   种族 → 只替换特定种族                                         │
│                                                                  │
│ 步骤 5: 开始处理                                                │
│   勾选 face_swapper → 点击"开始"                                │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ 常见问题快速解决                                                 │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│ Q: 参考人脸画廊是空的？                                         │
│ A: 拖动"预览帧"滑块切换到有人脸的帧                             │
│                                                                  │
│ Q: 如何查看视频中有哪些人脸？                                   │
│ A: 选择"参考人脸"模式，拖动"预览帧"滑块浏览                     │
│                                                                  │
│ Q: 只想替换视频中的一个人？                                     │
│ A: 使用"参考人脸"模式，在画廊中选择该人的脸                     │
│                                                                  │
│ Q: 想替换所有人但保留某些人？                                   │
│ A: 使用"多人脸"模式 + 过滤条件（性别/年龄/种族）                │
│                                                                  │
│ Q: 替换效果不自然？                                             │
│ A: 1. 勾选 face_enhancer 处理器                                │
│    2. 调整"人脸蒙版模糊"参数                                    │
│    3. 使用高质量的源图片                                        │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ 实用技巧                                                         │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│ ✓ 使用"预览帧"滑块浏览视频，找到最清晰的人脸帧                  │
│ ✓ 参考人脸距离从 0.7 开始尝试，根据效果调整                     │
│ ✓ 先用图片测试效果，满意后再处理完整视频                        │
│ ✓ 使用 GPU 可以大幅提升处理速度                                 │
│ ✓ 源图片要求：清晰、正面、光线好、表情自然                      │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
