FaceFusion 工作流程切换指南
=============================

当前问题：instant_runner 完成分析后不继续处理

三种工作流程对比：
------------------

1. instant_runner（即时运行）
   - 点击"开始"立即执行
   - 适合快速测试
   - 问题：任务可能卡在队列中

2. job_runner（任务运行器）
   - 可以看到任务队列
   - 可以管理多个任务
   - 推荐用于批量处理

3. job_manager（任务管理器）
   - 完整的任务管理界面
   - 可以暂停、恢复、删除任务
   - 适合复杂项目


如何切换工作流程：
------------------

方法 1：在界面切换
1. 找到"界面工作流程"下拉菜单
2. 选择 "job_runner" 或 "job_manager"
3. 界面会自动切换

方法 2：启动时指定
编辑 启动FaceFusion.bat，添加参数：
python facefusion.py run --ui-workflow job_runner


推荐操作步骤：
--------------

步骤 1：切换到 job_runner
1. 在界面找到"界面工作流程"
2. 选择 "job_runner"
3. 会看到任务列表界面

步骤 2：检查任务状态
- 查看是否有卡住的任务
- 如果有，删除或重新提交

步骤 3：重新提交任务
1. 上传源文件和目标文件
2. 配置参数
3. 点击"添加任务"
4. 点击"运行任务"


instant_runner 卡住的可能原因：
--------------------------------

1. GPU 初始化失败
   - 检查终端是否有 CUDA/TensorRT 错误
   - 运行: 验证GPU库安装.bat

2. 任务队列阻塞
   - 已清理（刚才运行了清理脚本）

3. 处理器未选择
   - 确保勾选了 face_swapper

4. 输出路径问题
   - 确保输出路径可写
   - 不要使用中文路径


调试步骤：
----------

1. 查看终端输出
   - 启动 FaceFusion 后
   - 提交任务
   - 观察终端是否有错误信息

2. 检查 GPU 状态
   - 打开任务管理器
   - 查看 GPU 使用率
   - 如果是 0%，说明 GPU 未工作

3. 验证 GPU 库
   运行: 验证GPU库安装.bat
   应该看到：
   - [OK] cuDNN 已安装
   - [OK] TensorRT 已安装
   - CUDA: YES
   - TensorRT: YES

4. 测试简单任务
   - 使用小视频（几秒钟）
   - 只勾选 face_swapper
   - 看是否能完成


当前建议：
----------

1. 关闭 FaceFusion

2. 运行验证：
   验证GPU库安装.bat

3. 重新启动：
   启动FaceFusion.bat

4. 切换工作流程：
   选择 "job_runner"

5. 查看终端输出
   看是否有错误信息

6. 重新提交任务
   观察是否正常处理


如果还是不行：
--------------

可能需要使用 CPU 模式：
1. 取消勾选 CUDA 和 TensorRT
2. 只使用 CPU
3. 速度会慢，但更稳定

或者检查是否是 Python 3.13 兼容性问题：
- onnxruntime-gpu 1.24.4 可能与 Python 3.13 不完全兼容
- 考虑降级到 Python 3.11
