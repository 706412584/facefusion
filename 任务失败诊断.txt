FaceFusion 任务失败诊断
========================

错误信息：
----------
[FACEFUSION.JOB_RUNNER] 正在运行队列任务 None
[FACEFUSION.JOB_RUNNER] 任务 None 处理失败

问题分析：
----------
任务 ID 是 None，说明任务创建失败，可能原因：

1. 源文件或目标文件路径问题
   - 文件不存在
   - 路径包含特殊字符
   - 临时文件已被删除

2. 输出路径问题
   - 输出目录不存在
   - 没有写入权限
   - 路径包含中文或特殊字符

3. 参数验证失败
   - 必需参数缺失
   - 参数值无效

4. 权限问题
   - .jobs 目录没有写入权限


解决方案：
----------

方案 1：使用绝对路径（推荐）
---------------------------
1. 不要使用临时文件
2. 将源文件和目标文件复制到固定位置
   例如：D:\facefusion_files\source.jpg
        D:\facefusion_files\target.mp4

3. 设置输出路径为固定位置
   例如：D:\facefusion_files\output.mp4

4. 避免使用中文路径


方案 2：检查文件权限
--------------------
1. 检查 .jobs 目录权限
   右键 .jobs 文件夹 → 属性 → 安全
   确保当前用户有"完全控制"权限

2. 检查输出目录权限
   确保输出路径可写


方案 3：使用命令行模式（最稳定）
--------------------------------
不使用 Web 界面，直接用命令行：

python facefusion.py run ^
  --source-paths "D:\source.jpg" ^
  --target-path "D:\target.mp4" ^
  --output-path "D:\output.mp4" ^
  --processors face_swapper ^
  --execution-providers cuda tensorrt

这样可以避免 Web 界面的任务管理问题


方案 4：简化配置
----------------
1. 只勾选 face_swapper（不要勾选其他处理器）
2. 只勾选 CUDA（暂时不勾选 TensorRT）
3. 使用默认参数
4. 先测试小文件（几秒钟的视频）


立即尝试：
----------

步骤 1：准备文件
1. 创建文件夹：D:\facefusion_test
2. 复制源文件到：D:\facefusion_test\source.jpg
3. 复制目标文件到：D:\facefusion_test\target.mp4

步骤 2：在 FaceFusion 界面
1. 上传源文件：D:\facefusion_test\source.jpg
2. 上传目标文件：D:\facefusion_test\target.mp4
3. 输出路径：D:\facefusion_test\output.mp4
4. 只勾选：face_swapper
5. 勾选：CUDA
6. 点击"添加任务"
7. 点击"运行任务"

步骤 3：观察终端
查看是否有详细的错误信息


如果还是失败：
--------------

使用命令行模式（最可靠）：

1. 关闭 FaceFusion Web 界面

2. 运行命令：
python facefusion.py run --source-paths "D:\facefusion_test\source.jpg" --target-path "D:\facefusion_test\target.mp4" --output-path "D:\facefusion_test\output.mp4" --processors face_swapper --execution-providers cuda

3. 观察处理过程

4. 如果成功，说明是 Web 界面的问题
   如果失败，会看到详细的错误信息


常见错误和解决：
----------------

错误：FileNotFoundError
解决：检查文件路径是否正确

错误：PermissionError
解决：以管理员身份运行

错误：CUDA out of memory
解决：
- 降低分辨率
- 减少执行线程数
- 关闭其他占用 GPU 的程序

错误：Model not found
解决：等待模型下载完成


当前建议：
----------
1. 先用命令行模式测试
2. 如果命令行可以，说明是 Web 界面问题
3. 如果命令行也不行，说明是配置或文件问题
