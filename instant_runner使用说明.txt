Instant Runner 工作流程说明
==============================

问题：点击"开始"后，显示"正在分析 100%"就停止了

原因：
------
1. instant_runner 是"即时运行"模式
2. 任务会创建并加入队列
3. 如果有旧任务卡住，新任务无法执行

解决方案：
----------

方案 1：清理任务队列（推荐）
---------------------------
1. 运行: 清理任务队列.bat
2. 关闭 FaceFusion
3. 重新运行: 启动FaceFusion.bat
4. 重新提交任务


方案 2：重启电脑（最彻底）
--------------------------
1. 运行: 清理任务队列.bat
2. 重启电脑（让 GPU 库生效）
3. 运行: 启动FaceFusion.bat
4. 勾选 CUDA 和 TensorRT
5. 重新提交任务


方案 3：切换到 Job Runner 模式
-------------------------------
在界面上：
1. 找到"界面工作流程"下拉菜单
2. 从 "instant_runner" 切换到 "job_runner"
3. 这个模式可以看到任务队列
4. 可以手动管理任务


检查任务状态：
--------------
查看 .jobs 目录：
- .jobs/queued/ - 等待执行的任务
- .jobs/failed/ - 失败的任务
- .jobs/completed/ - 完成的任务

如果 queued 目录有文件，说明任务在等待
如果 failed 目录有文件，说明之前的任务失败了


为什么会卡住：
--------------
1. GPU 库未生效（需要重启电脑）
2. 旧任务状态异常（需要清理）
3. 处理器配置错误（检查是否勾选了处理器）


正确的处理流程：
----------------
1. 上传源文件（人脸照片）
2. 上传目标文件（视频）
3. 选择人脸（reference 模式）
4. 勾选处理器（face_swapper）
5. 勾选 CUDA（如果有 GPU）
6. 点击"开始"
7. 等待处理完成


当前建议：
----------
1. 先运行: 清理任务队列.bat
2. 重启电脑（让 cuDNN 和 TensorRT 生效）
3. 重新启动 FaceFusion
4. 验证 GPU 是否工作（任务管理器查看 GPU 使用率）
5. 重新提交任务

重启后 GPU 加速应该能正常工作，处理速度会快很多。
