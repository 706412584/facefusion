===============================================================
        FaceFusion 打包成 EXE - 快速开始指南
===============================================================

第一步：准备环境
---------------------------------------------------------------
1. 确保已安装 Python 3.10+
   python --version

2. 安装项目依赖
   pip install -r requirements.txt

3. 安装打包工具
   pip install pyinstaller

第二步：开始打包（三选一）
---------------------------------------------------------------
【方法 1】最简单 - 双击运行 build.bat

【方法 2】使用 Python 脚本
   python build_exe.py

【方法 3】手动打包
   pyinstaller --clean facefusion_simple.spec

第三步：测试程序
---------------------------------------------------------------
打包完成后：
   cd dist\FaceFusion
   FaceFusion.exe run --language zh

打包结果
---------------------------------------------------------------
位置: dist\FaceFusion\
大小: 约 850MB - 1GB

文件结构:
├── FaceFusion.exe      (主程序)
├── _internal\          (依赖文件，必须保留)
└── README.txt          (使用说明)

使用打包后的程序
---------------------------------------------------------------
启动中文界面:
   FaceFusion.exe run --language zh

启动英文界面:
   FaceFusion.exe run --language en

命令行处理:
   FaceFusion.exe headless-run --language zh -s source.jpg -t target.mp4 -o output.mp4

常见问题
---------------------------------------------------------------
Q: 打包失败？
A: 检查依赖安装，查看错误日志

Q: 程序无法运行？
A: 安装 Visual C++ Redistributable
   https://aka.ms/vs/17/release/vc_redist.x64.exe

Q: 如何隐藏控制台？
A: 在 facefusion_simple.spec 中设置 console=False

分发注意事项
---------------------------------------------------------------
✓ 必须包含整个 dist\FaceFusion\ 文件夹
✓ 不能只分发 FaceFusion.exe
✓ _internal\ 文件夹包含所有依赖
✓ 告知用户首次运行需要下载模型
