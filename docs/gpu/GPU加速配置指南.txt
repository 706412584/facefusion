Q: 我找不到"执行提供商"选项？
A: 可能的位置：
   1. 在"执行线程数"上方或下方
   2. 需要向下滚动页面
   3. 在"高级选项"或"性能"分组中
   4. 界面语言可能显示为"Execution Providers"

Q: 我勾选了 CUDA 但没有加速？
A: 检查：
   1. 是否安装了 NVIDIA 显卡驱动
   2. 是否有 NVIDIA 显卡
   3. 重启程序后再试
   4. 查看终端是否有错误信息

Q: 可以同时勾选多个吗？
A: 可以！程序会按优先级使用：
   CUDA > DirectML > OpenVINO > CPU
   推荐勾选多个作为备选

Q: DirectML 和 CUDA 哪个更快？
A: CUDA 更快（如果你有 NVIDIA 显卡）
   但 DirectML 兼容性更好，支持所有显卡

Q: 我的电脑很慢，怎么办？
A: 1. 确保勾选了 GPU 选项（DirectML 或 CUDA）
   2. 降低输出视频分辨率
   3. 减少执行线程数
   4. 只勾选必要的处理器（face_swapper）

Q: 如何知道是否在使用 GPU？
A: 1. 打开任务管理器
   2. 查看"性能" → "GPU"
   3. 处理时 GPU 使用率应该很高（50-100%）
   4. 如果 GPU 使用率很低，说明在用 CPU

如果你正在处理中且速度很慢：

步骤 1: 停止当前处理
   点击"停止"按钮

步骤 2: 检查显卡类型
   打开任务管理器 → 性能 → GPU

步骤 3: 配置执行提供商
   找到"执行提供商"复选框组
   勾选对应的 GPU 选项：
   - NVIDIA 显卡 → 勾选 CUDA
   - 其他显卡 → 勾选 DirectML
   - 不确定 → 同时勾选 DirectML 和 CPU

步骤 4: 重新开始处理
   点击"开始"按钮

步骤 5: 验证加速效果
   打开任务管理器查看 GPU 使用率
   应该看到明显的速度提升
