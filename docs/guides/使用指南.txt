===============================================================
              FaceFusion 完整使用指南
===============================================================

现在 FaceFusion 提供三种使用方式：

1. 桌面版（推荐新手）- 独立窗口应用
2. Web 版（功能完整）- 浏览器界面
3. 命令行版 - 批处理和自动化

===============================================================
                    快速开始
===============================================================

方式 1：桌面版（最简单）
--------------------------
双击：启动桌面版.bat

特点：
✓ 独立窗口，无需浏览器
✓ 界面简洁直观
✓ 适合单个文件处理
✓ 启动快速

方式 2：Web 版（功能完整）
--------------------------
双击：启动FaceFusion.bat

特点：
✓ 功能完整
✓ 支持批量处理
✓ 任务管理
✓ 可远程访问

方式 3：命令行
--------------------------
python facefusion.py headless-run --language zh -s source.jpg -t target.mp4 -o output.mp4

特点：
✓ 适合自动化
✓ 批处理脚本
✓ 服务器使用

===============================================================
                    桌面版使用步骤
===============================================================

1. 双击"启动桌面版.bat"
2. 点击"选择源文件" - 选择包含人脸的图片
3. 点击"选择目标文件" - 选择要处理的图片/视频
4. 点击"选择输出位置" - 指定保存位置
5. 选择处理器（如：人脸交换）
6. 点击"开始处理"
7. 等待完成

===============================================================
                    Web 版使用步骤
===============================================================

1. 双击"启动FaceFusion.bat"
2. 等待浏览器自动打开
3. 在界面中上传源文件和目标文件
4. 选择处理选项
5. 点击"开始"按钮
6. 等待处理完成并下载结果

===============================================================
                    语言设置
===============================================================

所有版本都支持中文和英文：

桌面版：默认中文

Web 版：
  启动时添加 --language zh 参数
  或设置环境变量：set FACEFUSION_LANGUAGE=zh

命令行：
  python facefusion.py run --language zh

===============================================================
                    系统要求
===============================================================

最低配置：
- Windows 10/11 (64位)
- Python 3.10+
- 8GB 内存
- 10GB 可用磁盘空间

推荐配置：
- Windows 11 (64位)
- Python 3.11+
- 16GB 内存

- 20GB 可用磁盘空间

===============================================================
                    安装依赖
===============================================================

基础依赖（必需）：
  pip install -r requirements.txt

桌面版额外依赖：
  pip install PyQt6

全部安装：
  pip install -r requirements.txt
  pip install PyQt6

===============================================================
                    常见问题
===============================================================

Q: 桌面版和 Web 版有什么区别？
A: 桌面版是独立窗口应用，简单易用；Web 版功能完整，
   支持批量处理和高级功能。

Q: 可以同时运行两个版本吗？
A: 可以，它们是独立的程序。

Q: 首次运行需要下载什么？
A: 首次运行会自动下载 AI 模型文件（约 1-2GB），
   需要网络连接。

Q: 处理速度慢怎么办？
A: 建议使用 NVIDIA GPU 加速，或降低输出质量。

Q: 支持哪些文件格式？
A: 图片：JPG, PNG, BMP, TIFF
   视频：MP4, AVI, MOV, MKV, WebM

Q: 如何获取更多帮助？
A: 查看 README.md 或访问项目主页
