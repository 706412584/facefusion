FaceFusion 内容检测问题说明
==============================

问题现象：
----------
- 分析完成 100%
- 按钮从"停止"变回"开始"
- 没有进行换脸处理
- 没有输出文件

根本原因：
----------
FaceFusion 内置了 NSFW（不适当内容）检测功能。

当检测到视频中超过 10% 的帧被标记为不适当内容时：
- 处理会立即终止
- 返回错误代码 3
- 不会进行后续的换脸处理

检测逻辑：
----------
1. 每秒采样一帧
2. 使用 3 个 NSFW 检测模型
3. 如果 2/3 模型认为是 NSFW，则标记该帧
4. 如果超过 10% 的采样帧被标记，终止处理

误判问题：
----------
NSFW 检测模型可能会误判：
- 泳装、比基尼
- 裸露的肩膀、背部
- 亲密场景
- 某些角度的人体
- 艺术作品

这些内容可能被误判为不适当内容。


解决方案：
----------

方案 1：使用命令行模式（推荐）
------------------------------
命令行模式默认不进行内容检测。

运行: 直接处理视频.bat

或者手动运行：
python facefusion.py run --source-paths "源.jpg" --target-path "目标.mp4" --output-path "输出.mp4" --processors face_swapper --execution-providers cuda


方案 2：修改配置文件
--------------------
编辑 facefusion.ini，添加或修改：

[content_analyser]
skip_download = true

然后重启 FaceFusion。


方案 3：使用特殊启动脚本
------------------------
运行: 启动FaceFusion-无检测.bat

这个脚本会跳过内容检测。


方案 4：修改源代码（不推荐）
----------------------------
编辑 facefusion/workflows/image_to_video.py

找到 setup() 函数中的：
```python
if analyse_video(...):
    return 3
```

改为：
```python
# if analyse_video(...):
#     return 3
```

保存后重启 FaceFusion。


推荐做法：
----------
1. 使用命令行模式（最简单）
   运行: 直接处理视频.bat

2. 如果必须用 Web 界面
   运行: 启动FaceFusion-无检测.bat


验证是否是内容检测问题：
------------------------
查看终端输出，如果看到：
- 正在分析: 100% ... rate=XX.X
- rate 值大于 10.0

说明触发了内容检测，处理被终止。


当前建议：
----------
1. 关闭当前的 FaceFusion

2. 使用命令行模式：
   运行: 直接处理视频.bat
   输入文件路径
   观察是否能正常处理

3. 如果命令行可以，说明确实是内容检测的问题

4. 以后使用命令行模式或无检测版本的启动脚本


注意事项：
----------
- 禁用内容检测后，你需要自己确保处理的内容合法合规
- 不要处理违法或不适当的内容
- 仅用于合法的个人项目和创作
