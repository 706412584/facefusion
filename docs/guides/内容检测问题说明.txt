FaceFusion 内容检测问题说明
==============================

问题现象：
----------
- 分析完成 100%（例如 rate=72.7）
- 按钮从"停止"变回"开始"
- 没有进行换脸处理，没有输出文件
- 任务进入 .jobs/failed/，错误码 3

根本原因：
----------
FaceFusion 内置 NSFW（不适当内容）检测。

当采样帧中超过 10% 被标记为不适当内容时：
- analyse_video() 返回 True
- process_step 返回错误码 3
- 处理立即终止，不做换脸

检测逻辑：
----------
1. 每秒采样一帧
2. 用 3 个 NSFW 检测模型（nsfw_1/2/3）
3. 2/3 模型认为是 NSFW → 标记该帧
4. 采样帧中被标记比例 > 10% → 终止

误判问题：
----------
NSFW 模型可能误判：泳装/比基尼、裸露的肩膀背部、亲密场景、
某些角度的人体、艺术作品等。

判断是不是这个原因：
--------------------
看终端"正在分析"那行的 rate：
- rate 显示为 0 → 正常
- rate 明显 > 10（如 25、40、72.7）→ 触发了内容检测

⚠️ 常见误导：
------------
早期文档建议"改 image_to_video.py / image_to_image.py"，这是**错的**。
这两个文件只是任务编排，真正的判定在：
- facefusion/workflows/to_video.py 的 analyse_video()
- facefusion/workflows/to_image.py 的 analyse_image()

解决方案（本 fork 已默认关闭）：
--------------------------------
本 fork 已把上述两个 analyse_* 函数改为直接 return 0，
并移除了对 content_analyser 的调用，所以正常情况下不会再触发。

若合并上游后又出现该问题（上游会周期性恢复检测），
按 docs/guides/已禁用内容检测说明.txt 复查并重新关闭即可。

历史文档中已失效的内容（不要再照做）：
--------------------------------------
- ❌ "运行 启动FaceFusion-无检测.bat" —— 该脚本不存在
- ❌ "在 facefusion.ini 加 [content_analyser] skip_download = true" —— 该 section 不存在，无效
- ❌ "编辑 image_to_video.py 的 setup()" —— 改错文件，无效
- ✅ 正确做法：确认 to_video.py / to_image.py 的 analyse_* 为 return 0

注意事项：
----------
- 关闭内容检测后，需自行确保处理内容合法合规
- 不要处理违法或不适当的内容
- 仅用于合法的个人项目和创作
