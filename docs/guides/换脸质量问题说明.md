# 换脸质量问题诊断和解决方案

## 问题现象
1. 个别帧跳过换脸（未处理）
2. 脸部模糊和清晰交替闪烁
3. 换脸不稳定

## 原因分析

### 1. 帧被跳过的原因
- **检测阈值太高**：某些角度/光线下人脸检测分数低于阈值
- **关键点定位失败**：面部关键点检测失败导致跳过
- **人脸选择器过滤**：不符合年龄/性别/种族筛选条件

### 2. 模糊清晰交替的原因
- **检测不稳定**：每帧检测到的人脸位置略有偏移
- **没有人脸跟踪**：每帧独立检测，缺乏帧间连续性
- **增强器不一致**：face_enhancer 在某些帧生效，某些帧不生效

## 解决方案

### 方案 1：降低检测阈值（已设置）
```ini
face_detector_score = 0.4  # 默认 0.5，降低到 0.3-0.4
face_landmarker_score = 0.4  # 默认 0.5，降低到 0.3-0.4
```
✅ 已在配置文件中设置

### 方案 2：增加检测角度（已设置）
```ini
face_detector_angles = 0 90 180 270  # 全方位检测
```
✅ 已在配置文件中设置

### 方案 3：使用 Reference Face（推荐）⭐
在界面设置：
1. 找到 "Face Selector" 区域
2. 设置 "Reference Face Position" = 0（使用第一帧作为参考）
3. 设置 "Reference Face Distance" = 0.6-0.8（相似度阈值）

**作用**：
- 锁定目标人脸，避免误检其他人
- 提高帧间一致性
- 减少闪烁

### 方案 4：启用 Face Enhancer（推荐）⭐
在界面设置：
1. Processors 中添加 `face_enhancer`
2. Face Enhancer Model: `gfpgan_1.4` 或 `codeformer`
3. Face Enhancer Blend: 80-100（混合比例）

**作用**：
- 统一提升所有帧的清晰度
- 减少模糊清晰交替
- 改善整体质量

### 方案 5：启用 Expression Restorer（可选）
在界面设置：
1. Processors 中添加 `expression_restorer`
2. Expression Restorer Factor: 80-100

**作用**：
- 保持表情一致性
- 减少面部扭曲
- 提高自然度

### 方案 6：调整 Face Swapper 参数
在界面设置：
1. Face Swapper Model: `inswapper_128` 或 `simswap_256`
2. Face Swapper Weight: 85-95（降低可能更稳定）
3. Face Swapper Pixel Boost: 256-512（提高质量）

### 方案 7：使用更好的 Face Mask
在界面设置：
1. Face Mask Types: `occlusion`（已设置）
2. Face Mask Blur: 0.3-0.5（边缘柔和）
3. Face Mask Padding: 适当增加（如 5 5 5 5）

## 推荐配置组合

### 配置 A：稳定优先
```
Processors: face_swapper, face_enhancer
Face Detector Score: 0.35
Face Landmarker Score: 0.35
Reference Face Distance: 0.7
Face Enhancer Blend: 90
Face Swapper Weight: 90
```

### 配置 B：质量优先
```
Processors: face_swapper, face_enhancer, expression_restorer
Face Detector Score: 0.4
Face Landmarker Score: 0.4
Reference Face Distance: 0.75
Face Enhancer Model: gfpgan_1.4
Face Enhancer Blend: 100
Face Swapper Pixel Boost: 512
```

### 配置 C：速度优先
```
Processors: face_swapper
Face Detector Score: 0.45
Face Landmarker Score: 0.45
Reference Face Distance: 0.8
Face Swapper Model: inswapper_128_fp16
```

## 检查方法

### 1. 使用预览功能测试
- 播放预览，观察是否有跳帧
- 拖动滑块，检查每一帧
- 找到问题帧，调整参数重试

### 2. 查看日志
启动时添加 `--log-level debug` 查看详细信息：
```bash
python facefusion.py run --language zh --ui-workflow instant_runner --log-level debug
```

查找类似信息：
- "No faces detected" - 检测失败
- "Face score too low" - 分数不够
- "No matching face" - 参考脸不匹配

### 3. 逐步排查
1. 先只用 face_swapper，看是否跳帧
2. 如果跳帧，降低检测阈值
3. 如果闪烁，添加 face_enhancer
4. 如果还不稳定，设置 reference face

## 注意事项

1. **处理速度**：
   - 添加处理器会降低速度
   - face_enhancer 约降低 30-40% 速度
   - expression_restorer 约降低 20-30% 速度

2. **显存占用**：
   - 多个处理器会增加显存占用
   - 8GB 显存可以同时运行 2-3 个处理器
   - 如果显存不足，使用 moderate 策略

3. **质量 vs 速度**：
   - 高质量 = 慢速度 + 高显存
   - 快速度 = 可能不稳定
   - 需要根据需求平衡

## 常见问题

**Q: 为什么有些帧完全没换脸？**
A: 检测阈值太高或角度不支持，降低 score 到 0.3-0.35

**Q: 为什么脸部一会清晰一会模糊？**
A: 添加 face_enhancer 统一处理所有帧

**Q: 为什么换了其他人的脸？**
A: 设置 reference_face_distance，锁定目标人脸

**Q: 如何提高稳定性？**
A: 使用 reference face + face_enhancer 组合
