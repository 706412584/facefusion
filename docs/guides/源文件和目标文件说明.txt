┌──────────────────────────────────────────────────────────────────┐
│ 简单理解                                                         │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│ SOURCE (源文件) = 你想要的人脸                                  │
│ TARGET (目标文件) = 需要被换脸的图片/视频                       │
│                                                                  │
│ 结果 = 把 SOURCE 的脸换到 TARGET 上                             │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ SOURCE (源文件) - 提供人脸                                      │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│ 上传什么：                                                       │
│   • 一张包含你想要的人脸的图片                                  │
│   • 可以是自拍照、证件照、明星照片等                            │
│                                                                  │
│ 要求：                                                           │
│   ✓ 人脸清晰可见                                                │
│   ✓ 最好是正面照                                                │
│   ✓ 光线充足                                                    │
│   ✓ 表情自然                                                    │
│   ✓ 没有遮挡（不要戴口罩、墨镜）                                │
│                                                                  │
│ 示例：                                                           │
│   ┌─────────────┐                                              │
│   │             │                                              │
│   │    😊       │  ← 你的自拍照                               │
│   │             │     或你想要的明星照片                       │
│   └─────────────┘                                              │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ TARGET (目标文件) - 需要被换脸的内容                            │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│ 上传什么：                                                       │
│   • 一张图片（照片、合影等）                                    │
│   • 或一个视频（电影片段、短视频等）                            │
│                                                                  │
│ 这是需要被替换人脸的内容：                                       │
│   • 如果是合影，可以选择替换其中某个人                          │
│   • 如果是视频，会替换视频中的人脸                              │
│                                                                  │
│ 示例：                                                           │
│   ┌─────────────┐                                              │
│   │  😊  😊     │  ← 一张合影                                 │
│   │             │     或一段视频                               │
│   └─────────────┘                                              │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ 实际案例说明                                                     │
└──────────────────────────────────────────────────────────────────┘

案例 1: 把自己的脸换到合影上
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SOURCE (源文件):
┌─────────────┐
│             │
│    😊       │  ← 你的自拍照
│   (你)      │
└─────────────┘

TARGET (目标文件):
┌─────────────┐
│  😊  😊     │  ← 朋友的合影
│ (A)  (B)    │     你想把自己的脸换到 A 的位置
└─────────────┘

操作:
1. SOURCE 上传你的自拍照
2. TARGET 上传朋友的合影
3. 选择"参考人脸"模式
4. 在画廊中点击 A 的脸
5. 开始处理

结果:
┌─────────────┐
│  😊  😊     │  ← A 的脸变成了你的脸
│ (你)  (B)   │     B 保持不变
└─────────────┘


案例 2: 把明星的脸换到自己照片上
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SOURCE (源文件):
┌─────────────┐
│             │
│    😎       │  ← 明星的照片
│  (明星)     │
└─────────────┘

TARGET (目标文件):
┌─────────────┐
│             │
│    😊       │  ← 你的照片
│   (你)      │
└─────────────┘

操作:
1. SOURCE 上传明星的照片
2. TARGET 上传你的照片
3. 选择"多人脸"或"单人脸"模式
4. 开始处理

结果:
┌─────────────┐
│             │
│    😎       │  ← 你的脸变成了明星的脸
│  (明星)     │     但保留你照片的姿势和背景
└─────────────┘


案例 3: 视频换脸
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SOURCE (源文件):
┌─────────────┐
│             │
│    😊       │  ← 你的照片
│   (你)      │
└─────────────┘

TARGET (目标文件):
┌─────────────┐
│  🎬 视频    │  ← 一段电影片段
│  😊 → 😊    │     主角在说话、移动
│  (主角)     │
└─────────────┘

操作:
1. SOURCE 上传你的照片
2. TARGET 上传视频文件
3. 选择"参考人脸"模式
4. 在画廊中选择主角的脸
5. 开始处理

结果:
┌─────────────┐
│  🎬 视频    │  ← 视频中主角的脸变成了你的脸
│  😊 → 😊    │     但动作、表情、说话都保留
│  (你)       │
└─────────────┘


┌──────────────────────────────────────────────────────────────────┐

你的截图显示：
┌─────────────┐
│  😊  😊     │  ← 这是一张两个人的合影
│             │
└─────────────┘

你应该这样操作：

1. SOURCE (源文件):
   上传你想要的人脸照片
   例如：你的自拍照、明星照片等

2. TARGET (目标文件):
   上传这张合影（你截图中的图片）

3. 选择要替换的人:
   - 选择"参考人脸"模式
   - 在画廊中点击左边或右边的人
   - 只有被点击的那个人会被替换


┌──────────────────────────────────────────────────────────────────┐
│ 常见问题                                                         │
└──────────────────────────────────────────────────────────────────┘

Q: 可以上传多张源图片吗？
A: 可以！程序会提取所有源图片中的人脸，计算平均特征。

Q: 源图片和目标图片可以是同一个人吗？
A: 可以，但没有意义。通常源和目标是不同的人。

Q: 目标文件可以是视频吗？
A: 可以！支持 mp4, avi, mov 等常见视频格式。

Q: 源图片的人脸需要和目标图片的角度一样吗？
A: 不需要！程序会自动调整角度和姿势。

Q: 如果目标图片有多个人，但我只想换其中一个？
A: 使用"参考人脸"模式，在画廊中选择要替换的那个人。

Q: 源图片的质量会影响结果吗？
A: 会！源图片越清晰、光线越好，换脸效果越自然。


┌──────────────────────────────────────────────────────────────────┐
│ 推荐的源图片要求                                                 │
└──────────────────────────────────────────────────────────────────┘

✓ 分辨率：至少 512x512 像素
✓ 人脸大小：占图片的 30% 以上
✓ 角度：正面或侧面不超过 45 度
✓ 光线：均匀、充足
✓ 清晰度：不模糊、不失焦
✓ 遮挡：没有口罩、墨镜、头发遮挡
✓ 表情：自然、不夸张

不推荐：
✗ 模糊的照片
✗ 光线太暗或太亮
✗ 人脸太小
✗ 角度太大（侧脸、低头、仰头）
✗ 有遮挡（口罩、墨镜、手）
